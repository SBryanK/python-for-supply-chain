# Python for Supply Chain

Notebooks, slides and handouts for the course. A new week appears here before it starts.

## Start here

Open `course_home/setup_guide.pdf` and set up your laptop once. It takes about 30 minutes.

## What is in each folder

| Folder | What it holds |
|---|---|
| `course_home/` | Course outline, setup guide, glossary, templates and guides |
| `data/` | The lesson data file and its description |
| `work/` | Your own files from Session 4 on. They stay on your laptop |
| `week_1_...` to `week_4_...` | One folder per session: notebook, slides (PDF), handout, recall questions |

## Get the new files each week

1. Open GitHub Desktop and choose this repository.
2. Click **Fetch origin**. If the button then says **Pull origin**, click it.
3. The new week folder is now on your laptop. Open the folder in VS Code.

## Run a notebook

1. In VS Code, open the notebook in its session folder.
2. Click **Select Kernel** at the top right and choose Python 3.12.
3. Click a code cell and press **Shift + Enter**. Run the cells from the top, in order.
